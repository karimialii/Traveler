# Travel Planner Web App

A modern, interactive travel planning application built with Next.js, React, and AI-powered itinerary generation. Plan your trips with personalized suggestions, hotel recommendations, and interactive maps.

## Features

- 🗓️ **Travel Dates Planning** - Input your destination, departure, arrival, and return dates
- 🏨 **Hotel Search & Selection** - Search and add multiple hotels with detailed information
- 🤖 **AI-Powered Itineraries** - Get personalized travel plans generated by Google Gemini AI
- 🗺️ **Interactive Maps** - Visualize your itinerary with Google Maps integration
- 📱 **Responsive Design** - Works seamlessly on desktop, tablet, and mobile devices
- ✅ **Real-time Validation** - Form validation with helpful error messages

## Tech Stack

- **Frontend**: Next.js 15+ with React 19
- **Styling**: Tailwind CSS
- **Language**: TypeScript
- **AI**: Google Gemini API
- **Maps**: Google Maps API
- **Hotels**: Booking.com API (via RapidAPI)
- **Python**: Backend script for AI generation

## Prerequisites

- Node.js 18+
- Python 3.8+ (for itinerary generation)
- API Keys:
  - [Google Gemini API](https://ai.google.dev)
  - [Google Maps API](https://console.cloud.google.com/apis/credentials)
  - [RapidAPI](https://rapidapi.com/DataCrawler/api/booking-com15) (for Booking.com)

## Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/Traveler.git
   cd Traveler
   ```

2. **Install Node.js dependencies**
   ```bash
   npm install
   ```

3. **Set up Python virtual environment**
   ```bash
   python3 -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   pip install google-generativeai
   ```

4. **Configure environment variables**
   ```bash
   cp .env.example .env.local
   ```
   
   Edit `.env.local` and add your API keys:
   ```env
   GOOGLE_GEMINI_KEY=your_gemini_api_key
   NEXT_PUBLIC_GOOGLE_MAPS_API_KEY=your_maps_api_key
   RAPIDAPI_KEY=your_rapidapi_key
   RAPIDAPI_HOST=booking-com15.p.rapidapi.com
   ```

5. **Run the development server**
   ```bash
   npm run dev
   ```

6. **Open your browser**
   Navigate to [http://localhost:3000](http://localhost:3000)

## API Keys Setup

### Google Gemini API
1. Go to [Google AI Studio](https://ai.google.dev)
2. Click "Get API Key" and create a new key
3. Add to `.env.local` as `GOOGLE_GEMINI_KEY`

### Google Maps API
1. Go to [Google Cloud Console](https://console.cloud.google.com/apis/credentials)
2. Create a new API key
3. Enable "Maps JavaScript API" and "Geocoding API"
4. Add to `.env.local` as `NEXT_PUBLIC_GOOGLE_MAPS_API_KEY`

### Booking.com API (RapidAPI)
1. Sign up at [RapidAPI](https://rapidapi.com)
2. Subscribe to [Booking.com API](https://rapidapi.com/DataCrawler/api/booking-com15)
3. Copy your API key
4. Add to `.env.local` as `RAPIDAPI_KEY`

## Usage

1. **Enter Trip Details** - Specify your destination, departure, arrival, and return dates
2. **Search & Select Hotels** - Search for hotels by name and add them to your trip
3. **Get AI Suggestions** - View your personalized travel itinerary with activities and recommendations
4. **View on Map** - See your itinerary visualized on an interactive map
